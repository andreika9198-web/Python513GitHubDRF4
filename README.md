# Проект викторины "AnimalQuiz API"

Данный проект включает в себя 3 основных раздела:
1) Работа с разделами (Sections)
2) Работа с контентом (Content)
3) Работа с вопросами и ответами (Questions)

Виртуальное окружение используемое для проекта: venv

1) После настройки виртуального окружения установите из файла requirements.txt
```bash
  pip install -r requirements.txt
```
2) Заполните файл .env согласно .env_sample
3) Создайте Базу данных (SQLite3) при помощи команды
```bash
  python manage.py ccdb
```
4) Создайте миграции при помощи
```bash
  python manage.py makemigrations
```
5) Приведите миграции при помощи
```bash
  python manage.py migrate
 ```
6) Выполните команду для создания пользователей с разным уровнем доступа
```bash
  python manage.py ccu
```
7) Запустите проект при помощи

```bash
  python manage.py runserver
```
Модели используемые в проекте:
Section (Раздел) с полями:
- title - Название раздела (уникальное)
- description - Описание раздела

Content (Контент) с полями:
- section - Раздел (связь с Section)
- title - Заголовок контента (уникальный)
- content - Содержание контента 
- 
Question (Вопрос) с полями:
- section - Раздел (связь с Section)
- description - Описание вопроса 
- question - Текст вопроса 
- answer - Правильный ответ (связь с Content)
- member_answer - Ответ пользователя

User (Пользователь) с полями:
- email - Email (уникальный, используется как логин)
- role - Роль (ADMIN, MODERATOR, MEMBER)
- first_name - Имя 
- last_name - Фамилия 
- phone_number - Номер телефона 
- is_active - Активность

Ролевая модель и разрешения:
- Реализованы кастомные разрешения для пользователей с ролями MODERATOR и ADMIN 
- Смотреть списки разделов, контента и вопросов могут все пользователи (включая неавторизованных)
- Смотреть подробную информацию о разделе, контенте и вопросе могут все пользователи 
- Создавать, изменять, удалять разделы и контент могут только авторизованные пользователи с ролью MODERATOR или ADMIN 
- Модератор может управлять контентом и вопросами 
- Администратор имеет полный доступ ко всем разделам и может удалять контент 
- Проверка ответов на вопросы доступна всем авторизованным пользователям

Реализована пагинация:
- Разделы (Sections): 3 записи на страницу 
- Контент (Content): 5 записей на страницу 
- Вопросы (Questions): 5 записей на страницу

Тестирование:

- Доступна по адресу: /swagger/ 
- Доступна в формате ReDoc: /redoc/
